# Support

Use this guide to choose the right public or private support channel for Maekon.

## General Support

For installation help, usage questions, documentation feedback, or non-security bug reports:

- Email: `support@maekon.dev`
- GitHub Issues: use public issues for reproducible non-security bugs and feature requests.

When opening a support request, include:

- Operating system and version
- Maekon version or commit SHA
- Install method or build command
- Relevant logs with secrets, tokens, and personal screen content removed
- Steps to reproduce, if the issue is reproducible

## Security Reports

Do not open public issues for vulnerabilities or sensitive security reports.

Use the process in [SECURITY.md](./SECURITY.md), preferably GitHub Private Vulnerability Reporting or `security@maekon.dev`.

## Response Expectations

General support is handled on a best-effort basis. Security reports follow the response targets documented in [SECURITY.md](./SECURITY.md).
